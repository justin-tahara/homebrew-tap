# homebrew-tap

Homebrew tap for [justin-tahara](https://github.com/justin-tahara)'s tools.

```
brew install justin-tahara/tap/kubectl-mole
```

| Formula | Description |
|---|---|
| [kubectl-mole](https://github.com/justin-tahara/kubectl-mole) | Watch Kubernetes workloads until they settle, then explain what broke |

Tools here ship as formulas, not casks: Homebrew quarantines cask
downloads, and Gatekeeper kills quarantined binaries that are not
notarized. Formula downloads are not quarantined.
